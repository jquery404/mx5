# MX5

**MX5** is an Android notifier application. It is designed to deliver notifications efficiently and reliably on Android devices.

## 🔧 Build Instructions

To build the project, ensure you have Android Studio and the Android SDK set up.

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/mx5.git
cd mx5
````

### 2. Build the Debug APK

Use Gradle to assemble the debug build:

```bash
./gradlew assembleDebug
```

### 3. Install on a Device

You can install the debug APK directly if a device is connected:

```bash
./gradlew installDebug
```

## 📦 Requirements

* Android Studio Arctic Fox or newer
* Android SDK 21+
* Java 11 or higher

## 🛠️ Modules

* **app/**: Main application module for Fact Kit
